# New Jersey — step 4 sweep (pastor searched against markers)

Step 4 of the research standard, run **one name at a time** through a real search
tool. Bulk search is not possible: DuckDuckGo HTML, DDG lite, Bing and Mojeek all
block automated querying and SermonAudio's search is JS-shelled. An attempt at
bulk produced files full of zeros that were the block, not the pastors; they were
deleted rather than kept.

Markers searched: abolition / abolish abortion / equal protection / preborn /
theonomy / postmillennial / Christian nationalism, per name.

**Result so far: 31 of 77 named leaders searched. No marker hits on any of them.**

## Cross-reference that already exists

Abolitionists Rising publishes its church register per state at
`abolitionistsrising.com/state-facts/new-jersey/`. It lists **one** abolitionist
church in New Jersey (Missio Dei, Glassboro), zero abolitionist organisations and
zero abolitionist businesses. That independently matches this sweep's finding, so
a name absent from both this sweep and that page is unlikely to be abolitionist —
but "unlikely" is not "searched", which is why the list above still stands.
